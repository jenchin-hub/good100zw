# 谷吉爸紫微

演講現場分享給聽眾的紫微斗數排盤網站（快速版原型）。

## 功能

- 填寫頁：姓名、性別、國曆/農曆（含閏月）、時辰、手機、Email、個資同意
- 命盤頁：十二宮盤面，點選宮位顯示三方四正（本宮橘色，三方與對宮黃色）
- 本命盤／大限／流年切換，生年四化可顯示或隱藏，三層四化以形狀區分
- 命宮主星、身宮、生年四化的簡短文字解讀
- 需求按鈕：詳細命盤解析、流年分析
- 名單後台：名單、需求標記、處理狀態、看命盤、複製 CSV、刪除

## 檔案

- `index.html`：整個網站（單一檔案）
- `docs/命盤介面說明_原文.md`：三方四正顯示方式的口述說明

## 技術說明

- 排盤使用開源程式庫 [iztro](https://github.com/SylarLong/iztro) 2.6.5，由 jsDelivr 載入
- 資料儲存目前使用 Claude artifact 的 `db` 功能（`window.claude.use("db")`），只有擁有者登入後填寫才會留下紀錄
- 直接用瀏覽器開啟 `index.html` 可以排盤，但不會儲存資料，也看不到後台
